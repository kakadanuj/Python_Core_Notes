# 02 – Collections

Lists, tuples, sets, frozensets and dictionaries.

| File                    | Concept                                                        |
|-------------------------|----------------------------------------------------------------|
| `List_basics.py`        | Indexing, list methods, mutability                             |
| `tuple_basics.py`       | Immutability, single-element tuple, packing and unpacking      |
| `set_operations.py`     | Unique values, union, intersection, difference, frozenset      |
| `dictionary_methods.py` | Key-value pairs, get() vs [], update, pop, nested dictionaries |

**Key takeaway:** Choose by need: changeable or fixed, unique values or key-value pairs.
