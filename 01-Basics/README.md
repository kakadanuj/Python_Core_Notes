# 01 – Basics

Data types, operators, user input and strings.

| File                           | Concept                                                                    |
|--------------------------------|----------------------------------------------------------------------------|
| `01_data_types.py`             | int, float, str, bool, complex                                             |
| `02_operators.py`              | Arithmetic, assignment, comparison, logical, bitwise, membership, identity |
| `03_input_and_type_casting.py` | input() always returns a string, so convert it                             |
| `04_string_methods.py`         | String methods, indexing and slicing                                       |

**Key takeaway:** Python decides the data type at runtime, and input() always gives a string until you convert it.
